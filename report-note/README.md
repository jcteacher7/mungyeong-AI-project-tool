# 문경 취재 노트

4학년 사회 조사하기(시간축) 10~14차시에 쓰는 웹앱입니다. 모둠이 과거·현재 취재 노트에 카드를 쌓고, 아이마다 연결 한 줄을 쓰고, 14차시에 과거와 현재를 비교합니다.

- 학생용: `report-note/?start=1` (항상 반 고르기부터)
- 선생님용: `report-note/?t=1` (또는 제목을 1초쯤 누르기) → 네 자리 암호 (처음 1234)

## 저장

새로 실행할 SQL은 없습니다. 사진 짝·성찰 앱과 같은 Supabase `entries` 표를 씁니다.

- `group_id 911`, key `cfg` — 설정(반·명단·모둠·열린 칸·문구·암호)
- `group_id 910`, key `c:<반>:<모둠>:<장>:<칸>:<id>` — 카드 한 장 (장: past·now·cmp)
- `group_id 910`, key `l:<반>:<학생>:<장>` — 연결 한 줄
- `group_id 901` — 성찰 앱 명단을 읽어 오기만 합니다.

기록은 링크를 아는 사람이면 읽고 쓸 수 있는 수업용 설정입니다. 학기가 끝나면 `group_id`가 910, 911인 줄을 지웁니다.
