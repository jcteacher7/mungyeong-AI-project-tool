# 나의 배움 돌아보기

차시마다 학생이 1~2분 안에 자기평가를 하고, 그 기록이 계속 쌓여 성장이 보이도록 만든 웹앱입니다.

## 흐름

1. **이름 고르기** — 로그인 없이 명단에서 자기 이름을 누릅니다.
2. **오늘 돌아보기** — ATL 세 가지(사고기능·자기관리기능·협업기능)를 얼굴 세 단계로 고르고, "오늘 알게 된 것"을 한 줄 씁니다.
3. **내 성장 그래프** — 차시별 점이 선으로 이어져 보이고, 그동안 쓴 한 줄이 모여 있습니다. 인쇄·PDF로 저장해 학부모와 나눌 수 있습니다.
4. **선생님 화면** — 반 전체를 학생 × 차시 표로 보고, 이름을 누르면 그 학생의 그래프가 열립니다.

## 설치

새로 실행할 SQL은 **없습니다.** tuning-in과 같은 Supabase 프로젝트의 `entries` 표를 그대로 씁니다.

- `group_id 901`, key `cfg` — 설정(반 이름, 명단, 차시, 오늘 차시, 성찰 질문)
- `group_id 900`, key `r:<학생id>:<차시id>` — 성찰 기록 한 건

`config.js`에는 tuning-in과 같은 URL·anon 키가 들어 있습니다.

## 처음 할 일

화면 맨 아래 **선생님 화면** → 설정에서 반 이름, 학생 이름(한 줄에 한 명), 차시 이름을 넣고 저장합니다. 그다음 수업마다 **오늘 차시**만 바꿔 주면 됩니다.

학생 이름과 차시 이름은 나중에 고쳐도 기존 기록이 이름으로 이어집니다. 다만 이름의 철자를 바꾸면 새 사람으로 보니, 오타는 처음에 고쳐 두는 편이 좋습니다.

## 알아 둘 점

기록은 링크를 아는 사람이면 누구나 읽고 쓸 수 있는 상태입니다(수업용 설정). 학기가 끝나면 Supabase에서 `group_id`가 900, 901인 줄을 지우면 됩니다.
