# 언어생활 자가진단

아이들이 19문항 자가진단을 하고 신호등 결과를 본 뒤 다짐을 남기는 앱입니다. 선생님은 암호로 들어가 반별로 분석합니다.

- 아이들 주소: `language-check/`
- 선생님 주소: `language-check/teacher.html`
- 숨은 입구: 아이들 화면의 제목을 3초 안에 5번 누르면 선생님 페이지의 암호 화면으로 갑니다.

## 처음 설정

1. Supabase 왼쪽 메뉴에서 **SQL Editor**를 누르고 **New query**를 누릅니다.
2. `schema.sql` 전체를 붙여넣고 **Run**을 누릅니다.
3. 다시 **New query**를 누르고 아래 한 줄을 붙여넣습니다. 따옴표 안을 8자 이상의 암호로 바꾼 뒤 **Run**을 누릅니다.
   ```sql
   select lc_set_password('여기에-암호를-적으세요');
   ```
4. 선생님 페이지의 **④ 관리**에서 반과 명단을 넣습니다.

암호를 바꾸고 싶을 때도 3번을 다시 실행합니다.

## 저장과 잠금

- 표를 공개하지 않습니다. 아이들 화면은 명단 보기, 답 넣기, 다짐 넣기만 할 수 있습니다.
- 답을 읽고 고치고 지우는 일은 모두 서버에서 암호를 확인합니다. 10번 틀리면 10분 동안 잠깁니다.
- 아이들이 이름을 골라야 하므로 명단의 이름은 아이들 주소를 아는 사람에게 보입니다.
- 기록은 ④ 관리에서 지웁니다. 지운 기록은 되살릴 수 없습니다.

## 고칠 때

- 문항과 점수 기준은 `survey.js`에 있습니다. 영역별 문항 수를 바꾸면 `schema.sql`의 `lc_submit`도 함께 고칩니다.
- 안내글과 다짐 칸 예시는 ④ 관리에서 고칩니다.
- Supabase 무료 프로젝트는 오래 쓰지 않으면 멈출 수 있으니, 방학 뒤에는 수업 전에 주소를 열어 확인합니다.
